## 📖 Описание

**Defender** - это классическая tower defense игра, разработанная на Unity, где игрок защищает свою базу (кукурузное поле) от наступающих врагов-трентов, используя арбалет для стрельбы стрелами. Игра сочетает в себе элементы стратегии, точности и прогрессии персонажа.

## 🎮 Игровая механика

### Основной геймплей
- **Цель**: Защитить кукурузное поле от врагов-трентов
- **Управление**: Мышь для наведения и стрельбы из арбалета
- **Система уровней**: Прогрессивное увеличение сложности с каждым уровнем
- **Экономика**: Сбор кристаллов за убийство врагов для улучшений

### Игровые элементы
- **Арбалет**: Автоматическое наведение на курсор мыши с кулдауном стрельбы
- **Стрелы**: Летят в направлении наведения с настраиваемой скоростью и уроном
- **Враги**: Тренты с анимацией ходьбы, движущиеся к базе игрока
- **База**: Кукурузное поле с системой здоровья и возможностью улучшений

### Архитектурные паттерны

#### 1. **MVC (Model-View-Controller)**
- **Model**: `Corn.cs` - игровая логика и состояние
- **View**: `HealthUI.cs`, `CrystalUI.cs`, `LevelUI.cs` - отображение данных
- **Controller**: `LevelController.cs` - управление игровым процессом

#### 2. **Singleton Pattern**
- `LevelController` использует статические свойства для глобального доступа к состоянию уровня
- `Enemy.ActiveEnemies` - статический список для управления активными врагами

#### 3. **Object Pooling** (неявный)
- Префабы `Arrow` и `Treant` переиспользуются через `Instantiate/Destroy`

#### 4. **Observer Pattern**
- UI компоненты подписываются на изменения данных через `Update()`

## 🚀 Как играть

### Управление
1. **Наведение**: Двигайте мышь для наведения арбалета
2. **Стрельба**: Удерживайте левую кнопку мыши для стрельбы
3. **Меню**: Используйте кнопки интерфейса для навигации

### Стратегия
1. **Точность**: Старайтесь попадать в движущихся врагов
2. **Экономия**: Собирайте кристаллы для улучшений
3. **Прогрессия**: Улучшайте здоровье базы между уровнями
4. **Выживание**: Защищайте базу от атак врагов

### Цели
- **Победа**: Уничтожьте всех врагов на уровне
- **Поражение**: Не дайте врагам уничтожить вашу базу
- **Прогрессия**: Проходите уровни для увеличения сложности

## 📁 Структура кода

### Принципы разработки
- **SOLID**: Соблюдение принципов объектно-ориентированного программирования
- **DRY**: Избежание дублирования кода
- **Separation of Concerns**: Разделение ответственности между компонентами
- **Modularity**: Модульная архитектура для легкого расширения

### Соглашения именования
- **Классы**: PascalCase (например, `LevelController`)
- **Методы**: PascalCase (например, `TakeDamage`)
- **Поля**: camelCase с префиксом `_` (например, `_currentSpeed`)
- **Константы**: PascalCase (например, `Constants.Level`)
